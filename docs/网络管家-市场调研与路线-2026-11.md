# 从「代理客户端」到「一台电脑的网络管家」

> 调研时间：2026-11-14　对象：Windows 桌面端网络工具　基准版本：VPNTray 1.0.1
> 目的：回答一件事 —— 现在的 VPNTray 已经不只是个代理软件了，下一步往哪走才不会变成「又一个系统优化大师」。

---

## 0. 一句话结论

**市场上「出口加速」和「系统优化」都挤满了人，唯独「这台电脑的网络为什么不对」这一层没人好好做。**
我们的 13 项体检 + 就地修复已经踩在这条缝上；下一步不是加更多「加速」功能，而是把「诊断 → 解释 → 修复 → 验证 → 留证」做成这个软件的骨架，让加速器只是其中一个模块。

---

## 1. 我们手上已经有什么（按能力盘点）

| 能力 | 现状 | 在「解决所有网络问题」里的位置 |
|---|---|---|
| 出口代理 / 分流 | mihomo + 订阅 + 模块化规则，成熟 | 解决「国外站点」；对「本机故障」无解 |
| 场景模块 | `data/modules/*.json`，18 种规则、可增删 | 已经是「策略即数据」，可复用成「修复策略包」 |
| 体检 + 修复 | 13 项（链路/网关/DNS/代理/内核/直连/MTU/hosts/冲突/IPv6/投毒） | **最稀缺的资产**，但目前只覆盖「通不通」 |
| 本机 DNS 兜底 | 127.0.0.1:53 + 交易域名代理 DoH | 解决 Node/c-ares 绕过系统代理 |
| 交易通道守护 | 出口 IP / REST / WS / 投毒 | 垂直场景样例，可抽象成「业务链路守护」 |
| 校园网 | 门户识别 + 自动重登 | 「多网络环境」的第一块 |
| 更新 / 自更新 | ed25519 无关，SHA256 校验 + 目录替换 | 分发底座 |
| AI 接口 | /ai/v1 双端点、40 工具、三级权限 | **竞品完全没有的层**：意图级操作整个网络栈 |
| 报告 | 纯文本可复制 | 下一步要能导出「给别人看」的证据 |

**缺口**：能诊断「不通」，还不能诊断「慢」「不稳」「偶发」「某个应用单独不行」；修复动作只有 13 个，且大多围绕代理自身。

## 2. 市场地图（按用户真实报障归类）

价格以官网公开页为准（PingPlotter / Speedify 已核对，其余随版本变动，标注「以官网为准」）。

### L1 出口与加速（我们已经在里面）
| 产品 | 定位 | 价格 | 弱点 |
|---|---|---|---|
| Clash Verge Rev / mihomo GUI 系 | 规则代理，极客向 | 免费 | 报障要自己看日志；无体检、无修复 |
| v2rayN / sing-box GUI | 同上 | 免费 | 配置心智负担高 |
| Proxifier | 强制单应用走代理 | 约 $40 买断 | 只解决「按进程分流」 |
| 迅游 / 雷神 / UU 加速器 | 游戏专线 | 月费 20–40 元 | 只保游戏；系统其他应用不管 |
| ExitLag / WTFast / GearUP | 海外游戏多路复用 | 约 $5–10/月（以官网为准） | 同上，且对国内网络问题无感 |
| Speedify | 多链路捆绑（Wi-Fi + 4G） | $4.99/月起、多年套餐 $179.99 | 需要第二出口；国内不可用 |

**结论**：这一层已经是红海，靠「更快」赢不了；靠「出事时第一个能说清原因」能赢。

### L2 诊断与修复（我们的主战场）
| 产品 | 定位 | 价格 | 弱点 |
|---|---|---|---|
| PingPlotter | 延迟/丢包/抖动时间线，定位到「第几跳开始坏」 | $6.99 / $29 / $90 每月（官网） | 只诊断不修；英文；对 DNS/代理/证书类问题无感 |
| Wireshark | 抓包圣经 | 免费 | 门槛极高，普通用户拿到 pcap 也不会看 |
| NetLimiter | 逐进程限速 + 流量统计 | 约 $30 买断（以官网为准） | 监控强、诊断弱，不含修复 |
| 360 断网急救箱 / 电脑管家网络修复 | 一键修 | 免费（捆绑） | 黑盒、不可解释、行为激进、卸载残留 |
| Complete Internet Repair / NetAdapter Repair | 十年前的「一键修」 | 免费/捐赠 | 面向 Win7 时代，无 IPv6/DoH/代理残留概念 |
| Windows 自带疑难解答 / 网络重置 | 系统级 | 随系统 | 只有「重置」这一档，重则重装网络栈，且不告诉你为什么 |

**结论**：**空档就在这里** —— 没有产品把「可解释的逐项诊断 + 分级修复（先软后硬）+ 修复前后对比 + 可复制证据」做完整。PingPlotter 证明了「有人愿意为『看见问题在哪』付月费」，它月费 6.99 美元买的其实是一张图。

### L3 DNS 与解析
dnscrypt-proxy（开源，DoH/DoQ/ODoH 全家桶）、AdGuard Home（自建，带拦截与统计）、NextDNS（云服务，按查询计费）、YogaDNS（Windows 上按域名分流 DNS）、Simple DNSCrypt（GUI 包装）、DNS Jumper（一键换 DNS）。
**弱点**：都要用户自己判断「该用哪个解析器」；没有一个根据「延迟 + 是否被投毒 + 是否支持 ECS」自动选。
**我们的优势**：已经能直问任意服务器的 A 记录并判定黑洞地址（`dns_poison` 项），把它产品化就是「DNS 体检 + 优选 + 一键 DoH」。

### L4 系统级「优化」（流量最大、信任最低）
WinUtil（Chris Titus，装机一条龙）、Optimizer（hellzerg）、Sophia Script、Win11Debloat、O&O ShutUp10、WPD、NTLite、Dism++。
**共性**：改注册表 / 关遥测 / 删预装应用 / 关更新 / 调服务。流量巨大，但两个问题：
1. **不可回滚**（或回滚靠「你自己先做还原点」）；
2. **不讲证据**（「关掉这个更快」——快多少？不知道）。
**我们的机会**：只碰**网络子系统**，每个动作都有「为什么、影响谁、怎么撤」。

### L5 流量与可见性
GlassWire（防火墙 + 流量地图 + 告警）、NetLimiter、TrafficMonitor（国产悬浮窗，46.9k star，2026-09 还在更新）、OpenNetMeter。
**弱点**：能看不能修；GlassWire 的告警是「某应用连了新地址」，对「为什么慢」没有判断。

### L6 局域网与设备
Fing、Advanced IP Scanner、Angry IP Scanner、`arp -a`。
**场景**：网关是谁、同网段有几台设备、谁在抢带宽、Xbox/打印机为什么连不上。
**我们已经有 `hotspot.local_ip/default_gateway`**，做「局域网地图」成本很低。

## 3. 五个判断（决定了下一步怎么走）

1. **用户报「网络坏了」时，80% 不是出口问题。**
   真实高频原因：系统代理残留（上次代理软件没退干净）、DNS 被投毒/被运营商劫持、MTU/PMTU 黑洞（能打开首页、图片和视频卡死）、IPv6 半死（先卡 3 秒再回落 IPv4）、hosts 被破解软件写死、系统时间偏差导致 TLS 证书校验失败、安全软件拦 WFP 过滤驱动、双网卡/虚拟网卡抢默认路由、代理链套代理。
   → 这些我们**已经能做一半**（13 项里覆盖了 8 项），只是没成体系、没成产品语言。

2. **「诊断」比「加速」更值钱，也更容易被信任。**
   加速器说不清为什么快；诊断器能指着一张图说「从第 7 跳开始丢包，那是运营商」。后者才会被截图发到群里。

3. **修复必须分级，且必须能撤。**
   分级：只读检查（永远安全）→ 可逆软动作（清缓存、重启适配器、切 DNS）→ 需要管理员（重置 Winsock、改 MTU、改路由）→ 破坏性（网络重置、重装驱动）。**每一档都要用户点头，且每一档都能一键还原。** 这是我们和「一键修」类工具的分水岭。

4. **AI 接口是超车点，但要给「意图」，别给「原语」。**
   netsh / PowerShell 是原语，模型用不好；`net.diagnose` / `net.fix` 是意图，模型能用。下一步应该把「域」做成工具：`dns.audit`、`wifi.audit`、`mtu.probe`、`route.trace`、`time.check`，每个都能独立回答一个问题。

5. **别做「全能优化」。** 一旦开始关服务、删组件、改注册表，就进入杀软误报 + 用户背锅的领域，且与「可解释」自相矛盾。守住「网络」这条边界，反而更容易做成品牌。

## 5. 路线图（三段，按「可交付」切）

### 5.1 阶段一：把它变成「网络管家」（1.1 系列）

目标：任何人打开软件，5 秒内知道「我的网现在什么状态、哪里不对、点一下能不能好」。

1. **扁平面板**：首页一张「网络健康卡」—— 上/下行实时、网关、DNS 实际生效值、代理是否接管、IPv6 状态、当前出口国家，每项旁边一个「为什么」小问号。
2. **DNS 域产品化**：`dns.audit`（对 A/B 两路解析比对、延迟、黑洞、CNAME 链）→ 一键切到最优（系统 DNS / DoH / 本机兜底三选一），带还原。
3. **路径质量**：`route.trace`（ICMP + TCP 双探针，逐跳延迟/丢包，识别「首跳就丢」= 本机/路由器问题）→ 一张时间线图，可导出 PNG/文本。
4. **应用级视图**：当前有多少进程在连外网、各走代理还是直连、被哪条规则命中（内核 API 已有 `/connections`）。这是「就这个软件不行」的唯一正确答法。
5. **时间与证书**：系统时间偏差 > 90 秒直接红（TLS 失败的头号隐形原因）+ 证书链检查。
6. **网络环境档案**：把「家里/学校/公司」的 DNS、代理、场景开关、校园网配置打包成 profile，按 SSID/网关自动套用。
7. **报告升级**：现在能复制文本，改成「可导出 HTML 报告」（含体检结论、证据截图、修复记录），一张图能发群、能甩给网管。

### 5.2 阶段二：体验与性能（1.2 系列）

8. **MTU/PMTU 落地**：不只探测，给出「建议值 + 影响面 + 一键应用 + 回滚」。
9. **TCP 参数只读诊断**：读 `netsh int tcp show global`，指出「自动调节级别被改过/拥塞算法被第三方软件换掉」，给建议但不自动改（改这个的软件 90% 是在乱改）。
10. **IPv6 判定**：全局地址有、但默认路由不通 = 半死，直接建议关（我们已经在内核侧强制关了 dns.ipv6，可以把逻辑提到系统层）。
11. **时延质量评分**：会议/游戏场景下采 jitter/loss 时间线，输出「过去 10 分钟通话质量」评分。
12. **瓶颈定位**：本机 loopback 基准 → 网关基准 → 出口基准 → 目标站点基准，四段对比直接指出瓶颈在哪一段。

### 5.3 阶段三：守护与平台（1.3 / 2.0）

13. **网络变更事件总线**：换网、代理被改、DNS 被改、防火墙新增规则 → 自动体检并留证。
14. **故障取证包**：用户点「出问题了」时，立即抓一份快照（route/arp/dns/connections/适配器/最近日志），打包成 zip，可直接发给客服/网管/AI。
15. **AI 运维代理**：把上面每个域做成 AI 工具，用户说「Zoom 卡」，模型按意图调度体检并给结论（我们的 /ai/v1 已经是这个形状）。
16. **动作目录（平台化）**：所有修复动作登记为「前置条件 / dry-run / 影响面 / 回滚」，第三方（含 AI）可按规定调用；这是 2.0 的地基。

## 6. 明确不做（避免变成「优化大师」）

- 注册表大扫除、一键关更新、批量删预装组件（WinUtil 的领域，不是我们的）
- 驱动批量更新（Snappy Driver Installer 的领域，风险极高）
- 自动改全局 TCP 参数（改完无法归因，用户会怪你）
- 写死 hosts 钉 IP（投毒会变，钉完就是半年后自己踩雷）
- 注册「加速服务 / 系统服务」常驻（用户最反感的一类行为）
- 任何没有 dry-run 和回滚的动作

## 10. 建议的第一步

不要一次铺开 8 个域。**先把 B（解析）+ C（路径）+ E（应用级）三个域做成「看得见的证据」**，因为这三个正好覆盖「打不开 / 卡 / 就这个软件不行」—— 也就是用户最常发的那三句话。D（性能）和 F（安全）留到 1.2，G（多网络）跟着校园网顺路做。

一句话：**把「体检」升级成「取证」，把「修复」升级成「有回滚的动作目录」，把「加速」降级成其中一个模块。**

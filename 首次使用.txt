VPN Tray — 使用说明
====================

一、开始用（30 秒）
--------------------
1. 把整个文件夹解压到任意位置（比如 D:\Tools\VPNTray）。
   注意：文件夹里的东西不要单独挪走，bin 和 _internal 是程序的一部分。
2. 双击 VPNTray.exe。右下角任务栏会出现一个绿色「V」图标。
3. 双击这个图标（或右键 → 打开控制台），浏览器会打开控制台页面。
4. 在左下角「订阅」输入框里粘贴你自己的 Clash 订阅链接，点「保存并连接」。
   链接形如：https://xxxx.com/api/v1/client/subscribe?token=xxxx
   （机场/服务商的“Clash 订阅”或“Clash 配置”地址，不是你登录的网址）
5. 等待 10 秒左右，右边会出现节点列表。点任意节点即可切换；
   不确定选哪个就点「自动优选」，程序会挑一个真正能上网的。

就这样。之后国外网站自动走代理，国内网站自动直连，不用管。


二、托盘图标
------------
右键图标 = 菜单（切换节点 / 模式 / 开关 / 打开控制台 / 退出）
双击图标 = 打开控制台
绿色 = 正常　黄色 = 启动或测速中　红色 = 出错了（看日志）


三、常用操作
------------
· 某个网站打不开：控制台点「自动优选」，或换个地区（新加坡 / 美国最稳）
· 国内网站变慢：模式切回「规则分流」
· 只想让浏览器走代理：关掉「系统代理」，浏览器扩展里填 127.0.0.1:7891
· 换机场：控制台「订阅」里换链接，点「保存并连接」
· 开机自动启动：控制台里「开机自启」打开


四、端口
--------
代理端口 7891（HTTP/SOCKS 混合）
控制台   7892
内核 API 9091
只监听本机 127.0.0.1，不对局域网开放。如果 7891 被别的软件占了，
打开 data\settings.json 把 mixed_port 改成 7892 之类的再重启程序。


五、出问题怎么办
----------------
· 双击没反应 / 图标不出现：看 data\logs\app.log 最后几行
· 提示端口被占：关掉其它代理软件，或改 data\settings.json 里的端口
· 关掉程序后上不了网：说明系统代理没还原，重新打开程序，走托盘「退出」
· 想彻底重置：删掉整个 data 文件夹，重新启动即可（订阅要重新填）
· Windows Defender 提示风险：这是 PyInstaller 打包程序的常见误报，
  在“保护历史记录”里选择“允许”即可


五之二、装了火绒（或 360 / 电脑管家）被拦住了怎么办
---------------------------------------------------
这几家安全软件会拦「没签名的程序改 IE 代理设置」，症状是：
  · 控制台里「系统代理」是关着的，但浏览器还是直连（7891 端口其实是通的）
  · data\logs\app.log 里反复出现
      [WARNING] app: 系统代理被其它程序改动，重新接管回 127.0.0.1:7891
      重新接管系统代理失败: [WinError 5] 拒绝访问。
  · 退出程序后可能残留 ProxyEnable=1，导致整台上不了网

解决办法（一次就好）：
  1) 火绒主界面 -> 右上角「☰ / 设置」->「信任区」->「添加文件」
     选中 VPNTray.exe；再把 bin\mihomo.exe 也加进去 -> 确定 -> 重启 VPN Tray
  2) 还在拦就去：安全设置 -> 系统防护 -> 系统加固，
     把「注册表防护 / IE 设置」「浏览器保护 / 主页与代理」这类规则改成允许或关掉；
     弹出拦截提示时选「允许」并勾「记住本次操作」也一样
  3) 确认放行了：app.log 里应该出现
      [INFO] sysproxy: 系统代理已开启 -> 127.0.0.1:7891
     并且不再有 WinError 5

已经断网的救法（还原失败留下的）：
  reg add "HKCU\Software\Microsoft\Windows\CurrentVersion\Internet Settings" /v ProxyEnable /t REG_DWORD /d 0 /f
  或者 Windows 设置 -> 网络和 Internet -> 代理 -> 关掉「使用代理服务器」

不想动安全软件也行：
  · 关掉控制台「系统代理」，浏览器装 SwitchyOmega，代理填 127.0.0.1:7891
  · 或者用 TUN 模式（不碰注册表，需要右键「以管理员身份运行」）


六、卸载
--------
托盘右键「退出」→ 关掉开机自启 → 删除整个文件夹。
程序不写注册表（除了开机自启那一项），不装驱动，不留后台服务。

八、第一次打开会遇到什么

1. 会先弹一份使用协议，读完点「我已阅读并同意」才能用；点「不同意并退出」会直接关掉程序。
   协议按版本记录，升级后会再问一次。
2. 左上角会显示订阅剩余流量；粘一条订阅链接进来，节点列表几十秒内就会出来。
3. 默认已经开了「系统代理」和「节点自愈」；不确定要不要开的东西，先别动。

九、如果连上了却打不开网页（代理冲突）

多半是机器上还开着别的代理软件（Clash Verge、v2rayN、SingBox 之类），它们在抢同一套东西：
系统代理注册表、PAC 自动配置、TUN 虚拟网卡。TUN 网卡最麻烦 —— 它直接改路由表，
你把系统代理关掉，流量照样被它接走。

处理办法：左栏最下面「关于 · 帮助」→ 点「检测」。它会列出：
  - 系统代理是不是开着、指向哪里、有没有 PAC
  - 还有哪些代理进程在跑（PID 都给你）
  - 有没有 Up 状态的 TUN/TAP 网卡
然后三个按钮，每个都会先问你再动手：
  - 关闭系统代理：立刻走直连
  - 结束冲突进程：把列出来的那几个进程关掉
  - 禁用 TUN 网卡：需要管理员权限，不是管理员会失败

注意：这个软件自己的内核不会被列进去，清理时也不会被误杀。

十、遇到问题怎么反馈

「关于 · 帮助」→ 点「反馈」，写一句标题和具体现象（什么时候开始、点了哪个按钮、报什么错），
程序会自动附上版本、系统、节点数、当前节点和最近 200 行日志，存到 data\feedback\ 目录，
同时打开一条预填好的 GitHub issue 页面。

日志在生成时已经自动打码：订阅链接里的 token、节点密码、uuid、完整 IP 都被替换掉了，
你可以先打开生成的 md 文件自己看一遍，确认没问题再提交。

十一、卡片可以折叠

左栏每一张卡的标题都能点，点一下收起、再点展开，状态会记住。
「关于 · 帮助」默认是收起的，需要检查更新或反馈时点开就行。

十二、纯净度是谁算的
  列表和地图上的「纯净度」不是本软件自己编的，来自公开的 IP 画像服务：
  首选 One-IP（数据源 ip.net.coffee），它给一个 0-100 的综合信任分，
  同时说明这个 IP 是住宅还是机房、有没有被标成代理/VPN/Tor、
  以及访问 AI 服务（ChatGPT / Claude 等）会不会被区别对待。
  One-IP 查不到时，才回退到 ipapi.is / ip-api.com，用本软件自己的扣分算法。

  你在界面上看到的分数后面会带来源，比如：
    纯净度 62（One-IP）· 一般       <- 第三方评分
    纯净度 72（ipapi.is）· 良好     <- 回退算法
  鼠标悬停节点能看完整标签，例如「机房/xx · AI:IDC」，
  意思是这是机房 IP、且 AI 服务会把它当数据中心处理（容易被拦）。
  这些数字仅供参考，不构成对任何服务的可用性承诺。

十二、TUN 模式（整机代理）

  系统代理只管「读系统设置」的程序。游戏、命令行工具、部分 Electron 应用不读，
  它们要么直连、要么自己带代理设置。想全都走代理，就用 TUN。

  打开方式：模式卡里「TUN 模式」开关 -> 需要以管理员身份运行程序。
  打开时程序会自动关掉系统代理（两个一起开会打架）。

  开了 TUN 之后：
    - 所有程序（含 codex、npm、git、游戏）都会走代理，不用再单独设环境变量
    - 切换 TUN 会重启内核，网络会断 2-4 秒
    - 关掉程序时会自动撤销，不会留下虚拟网卡

十三、看谁在联网（连接列表）

  点左边「连接」按钮，会列出当前所有活动连接：
    目标域名 / 进程名 / 命中规则 / 出口节点 / 上下行流量
  每 2 秒刷新，可以单条断开，也可以全部断开。

  「某个软件连不上」时先看这里，三种情况：
    - 目标压根不在列表里  -> 它根本没走代理（命令行工具常见），设 HTTPS_PROXY 或开 TUN
    - 在列表里但出口是 DIRECT -> 被规则放行了，要查规则不是换节点
    - 在列表里、走了节点、但打不开 -> 节点或目标站的问题，换个节点试试

十四、双击托盘图标弹出的是什么窗口

  优先是程序自己开的原生窗口（和以前一样，独立窗口、没有浏览器地址栏）。
  如果这台机器上原生窗口起不来（比如装了会注入进程的软件，日志里会写
  "控制台窗口无法启动：RuntimeError: Failed to resolve Python.Runtime.Loader.Initialize"），
  会自动改用 Edge / Chrome 的「应用模式」窗口——同样是一个没有地址栏的独立窗口，
  日志里会写「已用 Edge 的 app 模式打开控制台」。
  两个都不行才会退到普通浏览器标签页。

  关掉窗口只是关窗口，代理照常工作；真要退出请用托盘右键「退出程序」。

十五、日志里一直刷「图标文件缺失」/ 不知道自己装的哪一版

  2.2.2 起，日志第一行就写版本：
    INFO app: VPNTray 2.2.2 启动（frozen=True，Python 3.12.10）
  反馈问题时先把这一行复制过来，省掉一半来回。

  如果日志里出现（以前是每 2 秒刷一条，2.2.2 只在启动时提示一次）：
    WARNING tray: 图标文件缺失（打包时漏了 assets）：...\assets\app.ico
  说明你手上这个包不完整（常见于别人二次打包、只拷了 VPNTray.exe）。
  官方 zip 里图标在 _internal\assets\app.ico，换回官方包就好；不换也不影响功能，
  只是托盘图标变成系统的白板图标。
